# ⬡ Noah Resume Engine
### Production-Ready Standalone Career Processing Framework
**A Premium Workspace Module by SonicResume Group — ://sonicresume.com**

Noah Resume is a high-performance, responsive web application utility designed to capture, format, and structure dense career payloads into professional profiles. Built completely without volatile or expensive AI API dependency costs, the platform operates with extreme structural stability using Firebase for data storage and Stripe for subscription checkouts.

## 📁 Core Application Architecture (Routes)

The application frontend is fully mapped out using React Router with active components, matching form states, and responsive layouts:
*   **`/`**: High-converting public product landing index.
*   **`/pricing`**: Light-themed tier selector highlighting yearly, lifetime, and commercial buyout models.
*   **`/builder`**: Interactive multi-step form capture ledger for career history ingestion.
*   **`/summary`**: Account profile hub for generating and editing executive resume summaries.
*   **`/bullets`**: Responsibility parser for formatting accomplishment statement bullet points.
*   **`/contact`**: Integrated communication node routing to official Messenger and enterprise pages.
*   **`/privacy` & `/terms`**: Fully updated, legally compliant, whitelabelable protection policies.

## ⚙️ Technical Stack & Local Launch

*   **Frontend Engine:** Vite + React + TypeScript
*   **Styling Architecture:** Tailwind CSS + PostCSS
*   **Serverless Framework:** Vercel Functions (`/api` directory ecosystem)
*   **Data Tier:** Firebase Authentication & Firestore real-time database

### 🚀 Booting Up the Sandbox

1. Restore matching package trees:
   ```bash
   npm install
   ```
2. Populate your local `.env` environment variables using your Stripe keys and Firebase config tokens.
3. Execute the development loop:
   ```bash
   npm run dev
   ```
4. Verify code validity and compile the production-ready build:
   ```bash
   npm run build
   ```
